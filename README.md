# 🎯 AI Career Twin

AI Career Twin is an AI-powered career guidance system that analyzes resumes, extracts skills, predicts suitable career roles, identifies skill gaps, matches job roles, and generates personalized career roadmaps.

## 🚀 Features

- 📄 Resume Analysis
- 🧠 AI-based Career Prediction
- 🔍 Skill Extraction
- 📊 Skill Gap Analysis
- 💼 Job Role Matching
- 🗺️ Personalized Career Roadmap
- 📈 Machine Learning Model Comparison

## 🛠️ Technologies Used

- Python
- Streamlit
- spaCy
- NLTK
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ⚙️ How It Works

1. Upload your resume.
2. The system extracts relevant information and skills.
3. A suitable career role is predicted.
4. Existing skills and skill gaps are identified.
5. Job roles are matched with the user's profile.
6. A personalized career roadmap is generated.
